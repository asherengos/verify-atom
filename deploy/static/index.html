● the atom

one endpoint. one job: check this one thing for me, and prove you did.

POST a URL. Get back a proof packet — HTTP status, page title, body SHA-256, DNS resolution, TLS certificate — timestamped and Ed25519-signed, so anyone can verify it independently without trusting this server. Every verification is inscribed on a public, append-only board. No account. No API key.

curl -s -X POST https://this-host/verify \
  -H 'Content-Type: application/json' \
  -d '{"type":"http_observation","url":"https://example.com"}'
/llms.txt /key /board/feed /health

Building an agent? There's a machine-readable API doc at /llms.txt and an MCP server wrapper so MCP-compatible agents can call verification as a tool. Verify any packet's signature offline against the public key at /key — the math either checks out or it doesn't.
